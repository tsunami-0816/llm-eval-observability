## 分级口径

- P0：链路完全中断（接口 500、写库失败、跑批卡死）
- P1：数据不一致、中文乱码、跨存储对不上、缓存脏数据、SDK 主链路崩溃、防重失效
- P2：展示瑕疵、非核心交互问题 → `deferred`

## 本轮结论（R1）

- 发现 2 个 P1（Q-001 环境伪影+加固、Q-002 SDK hook 崩溃）+ 2 个 P2（Q-003/Q-004 deferred）。
- R1 修复后回归 **8/8 PASS**，open P0/P1 = 0，**收敛放行**。
- API 层 30 项首轮 28 PASS，2 FAIL 均已在 R1 修复并回归通过。
