# 07_联调

本目录存放第 7 步全链路联调的**证据**：

- `联调检查清单.md`（本地走查的清单 + 实测记录）
- `联调修复说明.md`（代码片段 + 修改影响分析 + 自测说明）

问题本身不进本目录，**统一记在项目根目录 `_问题台账.md`（来源阶段=7）**；回归结果也写回台账（`fixed` → `verified`、轮次日志），不再另产《联调问题清单》《联调回归验证报告》。

修复不限轮次，按收敛判据（台账 open P0/P1 数须单调下降）；同一根因 3 次修复无效或问题数回升 → 判定架构性问题并回流第 3 步。
对应提示词：`prompts/step07_全链路联调.md` 与 `prompts/appendixA_通用修复回归模板.md`。
