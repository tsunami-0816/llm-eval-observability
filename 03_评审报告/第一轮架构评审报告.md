## 2. 基线指标 → 架构机制映射核对（R14）

| 基线指标 | 架构里的支撑机制 | 判定 |
|---|---|---|
| M1 SDK 开销 ≤50ms | SDK aiohttp 异步上报，业务调用不等待 | ✅ 有机制 |
| M2 100 QPS 写入 | asyncio.Queue + batch insert ClickHouse | ✅ 有机制（QPS 是否达标 step8 压测验） |
| M3 100 万条聚合 ≤1s | ClickHouse 列式 + 按天分区 + ORDER BY 命中 | ✅ 有机制 |
| M4 100 case ≤60s | BackgroundTasks 串行跑，mock judge | ✅ 有机制 |
| M5 3 种框架 trace | SDK 包装 openai/deepseek/langchain Callback | ✅ 有机制 |
| M6 成本误差 ≤1% | COST_TABLE 硬编码 + usage 字段透传 | ✅ 有机制 |
| M7 看板首屏 ≤2s | Redis 30s 缓存聚合结果 | ✅ 有机制 |
| M8 上报故障不阻塞 | SDK 端 try/catch 全部异常，业务零感知 | ✅ 有机制 |

8/8 指标在架构上都有对应机制，无「基线写了但架构没设计」的悬空指标。
