# 技术架构设计文档 · llm-eval-observability

## 1. 技术选型
| 组件 | 选型 |
|---|---|
| 后端 | Python 3.11 + FastAPI |
| 数据库 | SQLite（轻量免部署） |
| 前端 | Vue3 + ECharts |
| 部署 | 直接uvicorn启动，无Docker |

## 2. 核心链路
```
业务代码调用LLM → @trace装饰器拦截
  → 记录input/output/latency/tokens/cost到SQLite
  → 返回结果
看板查询 → 聚合SQLite数据 → ECharts渲染
```

## 3. 数据模型
**traces**：id / project / model / input / output / latency_ms / tokens / cost / ts
**prompts**：id / name / version / content / created_at
**eval_cases**：id / input / expected / actual / score / is_bad / ts

## 4. 接口
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/traces | 记录调用 |
| GET | /api/traces | 查询调用列表 |
| GET | /api/dashboard/stats | 看板统计 |
| POST/GET | /api/prompts | Prompt版本 |
| POST/GET | /api/eval/cases | 评测集 |

## 5. 评审结论
P0=0，P1=0（项目简单，无复杂分布式）
